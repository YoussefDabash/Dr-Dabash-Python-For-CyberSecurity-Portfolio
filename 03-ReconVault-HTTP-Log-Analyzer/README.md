# 🛡️ ReconVault — HTTP Log Recon & Loot Database Manager
**Author:** Youssef Tamer Dabash (`Dr. Dabash`)

أداة بايثون احترافية لتحليل سجلات خوادم الويب الخام (`Raw HTTP Access Logs`) واستخراج النطاقات الفرعية (`Subdomains`)، عناوين البريد الإلكتروني (`Emails`)، عناوين `IP`، ومفاتيح `AWS API Keys` المسربة (`AKIA...`)، ثم تخزين الغنائم (`Loot`) بأمان داخل قاعدة بيانات **`SQLite3`** وتصدير تقرير فحص تنفيذي شامل.

---

## 🧩 المفاهيم البرمجية المتقدمة المطبقة في الأداة
1. **البرمجة الكائنية والوراثة (`OOP & Inheritance`)**:
   - الكلاس الأب `BaseAuditSession` يدير بيانات الفاحص، توليد معرف الجلسة العشوائي (`OP-XXXXXXXX`)، وحفظ وسوم النطاق (`*scope_tags`) في `Set` لمنع التكرار.
   - الكلاس الابن `LogReconAnalyzer(BaseAuditSession)` يرث الخصائص الأساسية عبر `super().__init__()` ويضيف محرك الـ `RegEx` وقاعدة البيانات.
2. **المولدات الكسولة (`Generators with yield`)**:
   - دالة `stream_log_lines()` تقرأ ملفات السجلات الضخمة سطراً بسطر باستخدام `yield` دون تحميل الملف بالكامل في الذاكرة العشوائية (`RAM`).
3. **المزخرفات (`Decorators @execution_timer`)**:
   - قياس الزمن الفعلي المستغرق في استخراج البيانات بدقة أجزاء الألف من الثانية دون تكرار كود حساب الوقت.
4. **التعبيرات النمطية والمجموعات (`RegEx & Capturing Groups`)**:
   - استخراج الـ `IPs`، الإيميلات، مفاتيح `AKIA`، وتفكيك الروابط إلى 4 مجموعات (`Protocol`, `Host`, `Port`, `Path`) باستخدام `.groups()`.
5. **الحماية من ثغرات حقن قواعد البيانات (`Parameterized SQLite3 Queries`)**:
   - حفظ النتائج في جدول `endpoints_loot` باستخدام المعاملات الآمنة `(?, ?, ?, ?, ?)` لمنع ثغرات `SQL Injection` في حال احتواء السجلات على حمولات خبيثة.

## 💻 طريقة التشغيل
```bash
python3 reconvault_log_analyzer.py
```
> **ملاحظة:** إذا لم يكن ملف `access_dump.log` موجوداً، يقوم السكريبت تلقائياً بإنشاء ملف سجلات تجريبي، ويحفظ النتائج في قاعدة بيانات `recon_vault.db` ويصدر التقرير النهائي في `final_engagement_report.txt`.
